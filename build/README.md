# DockYarp Deployment (NUKE)

This project contains the CI/CD pipeline for DockYarp using NUKE.

Agents will generate:
- Build pipeline (Clean, Restore, Compile, Test)
- Docker pipeline (build, tag, push)
- Publish pipeline (artifacts, releases)
- Local run scripts
- Integration with GitHub Actions or Azure DevOps

This project is intentionally empty. All logic will be generated by agents following OpenSpec.yaml.
