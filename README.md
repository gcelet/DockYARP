# DockYarp

DockYarp is a dynamic reverse proxy built on YARP (.NET 10), with:
- Docker auto-discovery
- Automatic ACME/TLS
- Dynamic routing
- Dynamic clusters
- Security middleware
- Admin API
- Full OpenSpec-driven architecture

All implementation is spec-driven with [OpenSpec](https://github.com/Fission-AI/OpenSpec): changes live
under `openspec/changes/`. See `AGENTS.md` for conventions.
